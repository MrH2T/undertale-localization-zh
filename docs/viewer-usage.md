# 本地 viewer 使用说明

运行项目根目录的 `start-viewer.cmd`，打开 http://127.0.0.1:8767 。服务只监听本机。现有第 60、90–99、140、220 页，共 13 页、156 个可编辑文字块；90–99 是 PDF 页序，此处与印刷页码相同。

## 阅读、编辑、保存

- 顶部选择页码，切换“原文 / 译文”。点击书页文字区域可定位并编辑对应段落。
- “编辑”收起或打开侧栏；宽窗口在右侧，窄窗口在书页下方。100% 按固定参考尺寸显示，缩放不重新换行。
- 修改后约 0.9 秒自动保存，也可“保存”或 Ctrl+S。切换、导出、载入前会先保存。
- 选中英文或罗马字，点“斜体”设置或取消斜体。格式范围跟随文字编辑移动，保存和再次载入时保留。中文使用正体。
- “排版”调整字号、行距倍数、文字框 X/Y/宽/高。“还原位置”恢复校准位置；原文遮罩不随译文框移动。
- 底栏提示文字溢出和框重叠，点击可定位。文字完整保存，不自动删字或缩小字号；PDF 遇到这些问题会停止导出。

## 导出与载入

点“导出”，输入 `90-99` 或 `60,140,220` 等 PDF 页序，可用逗号组合范围；只能选择已电子化的页面。

- **PDF**：使用当前 viewer 的断行和文字坐标，嵌入中文、英文、日文字体；正文是可搜索、可选中的文字，图像保留扫描。页尺寸与源 PDF 相同。生成后点“下载 PDF”；项目的 `private/exports/` 同时保留 PDF 和排版快照。勾选“PDF 附原文页”按每页原文、译文交替输出。
- **JSON 存档**：保存所选页的中英文本、斜体/语言范围、段落类型和关联、字号行距与坐标，不包含扫描图。保留这个文件可再次编辑；PDF 是阅读输出，不作为译文母稿。
- **载入**：选择 JSON 后先显示页码及文字块数量，点“载入文件”才替换这些页的译文和排版。自动备份当前版本；多页写入失败则回滚，下次启动也会恢复未完成的事务。其他页不受影响。

存档只用于同一本书、同一批已存在的页面结构。原书哈希、页图引用、原文、块 ID 和结构必须匹配；不允许用存档替换扫描图或原始 OCR。跨项目迁移需另行复制对应的私有素材目录。其他窗口改过同一页时会拒绝覆盖，请先复制未保存文字再刷新核对。

## 保存结构

母稿：`private/content/viewer/p0090.json` 等，UTF-8、两空格缩进。备份：`private/backups/viewer/`。源扫描及 OCR：`private/extracted/audit/samples/`。导出：`private/exports/`。不依赖浏览器缓存。

格式约定和读取流程见 [设计文档](viewer-design.md) 的“现行格式与导出实现”。原先三页的版式研究见 [校准记录](typography-calibration.md)。

正文使用 Noto Serif SC 450，英文使用 Source Serif 4 Text 正体及斜体，日文用 Noto Serif JP，标题/侧注用 Noto Sans SC。正文采用段落整体断行、中文标点禁则及两端对齐，末行自然收尾。窄栏与引句已逐页调整字号和间距。

90–99 已对照原 PDF 校准表格、列表、引文框、侧注和段落；译文仍为待校稿。截图中的游戏文字、照片、插图和页脚保留原图，不宣称整页所有文字都已结构化。

## 开发与复验

Python 依赖见 `viewer/requirements.txt`。浏览器字体在 `viewer/dist/fonts/`；PDF 静态字体由 `python viewer/build_pdf_fonts.py` 生成到 `viewer/pdf-fonts/`，每个字重有独立内部名称，避免 PDF 将正文与标题字重混用。字体许可保留在原字体目录。

运行 `python -m unittest discover -s viewer -p "test_*.py"`、`node --test viewer/test_composition.cjs viewer/test_files.cjs viewer/test_layout.cjs viewer/test_notes.cjs`。测试使用临时数据，不覆盖学习母稿。自动检查不能代替逐页原图对照和导出 PDF 的实际渲染检查。

## 对齐与段落接排

在“排版”中用“改宽时固定”选择左边、中心或右边；这决定改变宽度时哪一边不动，与段内文字对齐不同。“对齐吸附”使 X 或宽度接近同类同侧框的边缘时对齐，可关闭。

连续正文可启用“高度随文字”，再用“接在段后”和“段距”连接。第 94 页第 3–5、8–10 段已有样本。接排按实际文字高度计算，不把空框剩余高度算入段距；区域底线应设在下方图片或其他固定内容之前，越线会警告并阻止 PDF 导出。底线需手动设置，尚不自动识别所有图片障碍。

“清除首尾空行”只清理当前段落的开头和末尾，不吞掉双语对照的内部换行。“格式标记”显示保存的斜体与语言信息，只读；修改格式仍用选区和“斜体”按钮。

语言呈现规则见 translation-policy.md，统一提示词见 translation-prompt.txt。独立交互样张：http://127.0.0.1:8767/notes-demo.html 。注释功能现已按用户要求停用；正文只保留必要的简短括注。

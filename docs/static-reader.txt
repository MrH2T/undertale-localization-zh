静态阅读器（2026-10-23）

阅读地址：https://mrh2t.github.io/undertale-reader/
公开发布仓库：https://github.com/MrH2T/undertale-reader
可编辑源仓库：https://github.com/MrH2T/undertale-localization-zh （保持私有）

使用
打开网址自动进入书页，不需要 GitHub 登录、令牌或连接步骤。
支持搜索、目录、书签、缩放、原文/译文/对照和版本选择。
左右方向键翻页，Ctrl+F 或 / 打开全书搜索。
浏览器保存阅读位置、书签、最近文本和最多 12 张书页图片。
首次打开仅加载小型页目、当前页 JSON、当前页所需字体和图片；搜索时才加载全文搜索数据。
再次打开先读缓存并检查小型版本目录，未变内容直接复用。
main 是最新已发布版本；reader-v1 是固定版本。版本目录内的 SHA 也可直接输入。
公开静态页面不运行 PDF 导出，仍由本地 viewer 导出。

结构与修改
private/content/viewer/pNNNN.json 是唯一有效源稿，一页一个文件，一段一个固定 ID。
原文、译文、格式 spans、layout、structure 分开保存；细节见 page-data-format.txt。
“修改此页”打开源仓库 main 分支对应的文件；编辑该私有仓库仍需有写入权限。
小幅改字可在 GitHub 编辑，格式与版式调整建议用本地 viewer。
修改源文件后，提交到源仓库，再运行下方发布命令，网站才会更新。
若先在 GitHub 网页改了源文件，应先在本地 git pull，避免发布旧内容。

发布
python scripts/check_page_data.py
python scripts/publish_reader.py --output <undertale-reader 的独立本地检出目录>
发布脚本导出 main 和 reader-v1，只更新指定的公开仓库，然后由 GitHub Pages 部署。
它不会把源仓库历史、PDF、原始扫描、备份或访问令牌复制出去。
公开仓库 Pages 使用 Deploy from a branch → main → /(root)。
发布目录 data/catalog.json 记录版本；data/versions/<SHA>/pages/pNNNN.json
保留逐页结构化副本，index.json 是完整导出备份；manifest.json 是轻量页目，search.json 是按需搜索数据，均为可重建文件，不能当作另一份源稿修改。
data/images/<blob SHA>.jpg 存放阅读图片，相同图片在不同版本间复用。
公开程序仅从本站 fetch 这些静态文件，不调用私有 GitHub API。
旧公开快照保留以支持历史链接，不自动删除已发布版本。

公开范围
用户于 2026-10-23 明确确认公开全文和页面图片、无需授权阅读。
该确认改变发布范围，并非取得版权方授权；许可状态仍见 rights/status.json。
原内容仓库保持私有；公开版本的文本和图片可由任何访问者下载。

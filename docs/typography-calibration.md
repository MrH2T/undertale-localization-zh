# 字体与断行校准记录

2026-10-22。第 60、140、220 页，本地私人学习项目。

## 当前方案

中文正文 Noto Serif SC 450，20 px / 29 px；英文单独使用 Adobe Source Serif 4 的 Text 正文版，400 字重。Undertale、ikashita kōgeki、bibō 使用该字体真实斜体。日文 Noto Serif JP 400；标题、侧注、图注保留 Noto Sans SC。所有字体本地加载。

PDF 是扫描图加隐藏 OCR：Times-Roman、Times-Italic 等字体名来自不可见 OCR 层，没有嵌入原书正文的实际字体。因此不能据此认定原版使用 Times。Source Serif 4 是对照扫描后选定的编辑字体，未宣称精确识别原字体。其正体和斜体均为 4.005；来源、哈希、OFL 许可保存在 viewer/dist/fonts/。

## 换行处理

正文两端对齐，段末左齐。采用针对中英日混排的段落动态规划：按实际字体测量占宽，比较全段合法断点，优先控制松紧；英文单词内部不加字距、不拆字母；短语可在空格处断开，避免为整块不换行而产生过大空白。中文按字断行，并对词内断行增加代价；该代价不是语义审校。

前括号、前引号不落行尾，句号、逗号和后括号等不落行首；省略号、破折号按连续成对字符保留。相邻和行末标点只压缩实际字形周围的空白，最大半个字身；不缩放字形。超过当前处理范围、过长单词等回退浏览器排版，保留溢出提示。

先比较过浏览器原生两端对齐与 text-wrap:pretty。第 140 页日文和罗马字一行仍过松。整段试排配合标点空白压缩后，该日文例句与罗马字可同排一行。最终保留小幅字距调整，并允许多词英语短语按词间空格换行。侧注延续原书靠图一侧对齐；图注居中，不套用正文的两端对齐。

显示用行片段不写回原文或译文；改文字、字号、框宽会重新计算。缩放整个固定坐标页面时不重排。界面没有新增装饰或命名。

# 本地电子化与中英对照结构

当前目标是个人本地学习，不接 GitHub 远程、不部署网页。图像模型产生的中文版属于可再生的阅读衍生物；原扫描、校对文本与翻译记录分别保存。

## 文件结构

```text
docs/                         方法、结构说明，不包含整本书正文
schemas/segment.schema.json   段落数据约束
scripts/                      提取、校验与派生导出脚本
private/
  source/manifest.json        原文件绝对路径、SHA-256、大小；不重复复制大 PDF
  extracted/
    audit/                    全书文字、图像清单与 12 页抽样
    pages/p0060/              页面尺寸、扫描、词坐标及版面区域
  content/
    book.json                 书籍信息、章节与页码映射
    segments/p0060.json       按稳定 ID 保存原文、译文与证据位置
    assets/                   从原始扫描按坐标裁出的图，不经过生成式重绘
    glossary.json             术语、专名、日文读音及上下文
  experiments/p0060-direct-v1/ 提示词、原图、嵌字结果、参数与用量回执
  exports/                    本地对照阅读页 / PDF 等派生结果
```

## 页面与段落

- PDF 页码使用从 1 起的 `pdf_page`；印刷页码单独保存为字符串或 null，逐页核验，不假定全书偏移恒定。
- 页面保留尺寸和扫描哈希。区域坐标统一为左上角原点的归一化 `[x0,y0,x1,y1]`，范围 0–1；像素裁剪时由原始图尺寸转换。
- 每个标题、正文段、图注、旁注、列表项、表格、截图文本使用稳定 ID，如 `p0060-b002`。校订时 ID 不变；跨页段落关联多个区域和页码。
- `order` 表示人工确认的阅读顺序，图注通过 `asset_ids` 绑定图片，旁注通过 `related_segment_ids` 绑定正文，避免按 OCR 返回顺序串接。
- `source.raw` 保存未经修正的 OCR，`source.corrected` 保存看图校订文本；不覆盖旧 OCR。更正日志单独保留。
- `source.languages` 支持 en、ja 和混排；原书的日文例句与英文释义分别建块。中文翻译不能覆盖日文原文，也不应把错误 OCR 的日文猜成正确词语。
- `translation.zh_hans` 保存简体中文；`notes` 区分译注与原书内容。专名、双关及翻译问题关联术语表。

## 状态与版本

源文：`raw → corrected → reviewed`；译文：`empty → draft → reviewed`。图像模型输出先标记 `draft`，视觉清晰不代表语义审校完成。

每次译文记录对应的 `source_revision`。原文修订后旧译文自动视为待复核；不继续把它标为已审校。模型、提示词版本、参考图和实际 usage（未知填 null）保存到实验记录。

## 阅读与导出

建议采用“原页图像 + 中英段落对照”视图：点击段落高亮原图区域；段落显示英文、中文、图注、译注与校对状态。手机采用上下排列。图片使用原扫描裁剪，支持放大；日文例句保留原字形。

“整页中文嵌字”另作派生版本，与原图并列查看。它适合沉浸阅读，但编辑与搜索仍依赖段落数据。后续若要确定性排版，使用已审校译文覆盖指定文字区域，保留原始图片，不把全页重新生成作为唯一母版。

## 首批处理顺序

1. 保存源文件指纹；全书旧 OCR 和图像清单已提取。
2. 以第 60 页建立正文、图注、图片关联的模板；当前提供标题及首段的数据示例。
3. 用第 140、220 页扩展侧栏、英日截图、日文列表和双关处理；空 OCR 的目录需单独视觉转录。
4. 逐段校对英语和日语，再译成中文，保存修订与不确定项。
5. 形成小批试读后再扩展全书；按不同版式分别记录质量和用量。

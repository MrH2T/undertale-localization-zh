## 中国大陆规则

著作权法第十条规定复制权、信息网络传播权及翻译权。整本 OCR/重排、完整翻译、上传公开网站分别可能涉及这些权利；只放译文也不自动免除原作者权利。第十三条规定，翻译者行使其权利不得侵犯原作品著作权。

第二十四条的个人学习、研究或欣赏例外，不能简单扩展为面向公众提供全书。课堂教学或科研例外有对象与使用范围限制；评论中的适当引用须服务于评论目的，不影响作品正常使用、不不合理损害权利人利益。署名、免费、附购买链接或“侵删”声明均不自动构成许可。第五十二、五十三条列举未经许可翻译、复制及网络传播等行为；无盈利不当然排除民事责任。

来源：[国家版权局《中华人民共和国著作权法》](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)。

## 美国合理使用与 GitHub

美国合理使用需综合用途、作品性质、使用数量与实质性、市场影响。非商业只是考虑因素之一。完整电子版或译本可能替代原书或潜在授权译本，是不利因素；是否成立仍依具体事实判断。没有“少于某百分比就必然安全”的通用规则。

来源：[美国版权局合理使用说明](https://www.copyright.gov/fair-use/more-info.html)、[版权局 FAQ](https://www.copyright.gov/help/faq/faq-fairuse.html)。

GitHub 可根据 DMCA 通知处理涉嫌侵权内容；仓库或 Pages 可被限制访问。平台下架机制不等同法院最终认定，也不代表不盈利项目获得豁免。

来源：[GitHub DMCA 政策](https://docs.github.com/en/site-policy/content-removal-policies/dmca-takedown-policy)。

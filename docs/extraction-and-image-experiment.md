## 结果

选择 PDF 第 60 页 / 印刷页码 60「Getting it Localized」。它有 2 个标题、7 段正文、2 张照片及 2 条图注，适合测试正文密度、图文共存和段落完整性。它没有复杂日文对照，所以本次不能证明日文密集页也能达到相同效果。

使用内置 `image_gen.imagegen` 的图像编辑能力，直接输入整页图像和翻译要求。没有预先给出中文译文，没有用程序重新排版或覆盖文字。具体底层模型名称由工具决定，返回值未披露，不能声称本次使用了某个确定版本的 GPT Image。

## 视觉及译文检查

- 标题、7 段正文、两条图注均出现，没有发现整段遗漏；页码 60 保留。
- 中文字符清晰，段落未压住图片，未见明显文字溢出。英文专名大体保留。
- 少量表述需校对：`approach localization` 译成“看待本地化”，此处“开展本地化”更符合上下文；`a million different companies` 被弱化为“成千上万家公司”；末尾 `unsolicited offers` 译作“主动联系与报价”，其中“报价”比原文更具体。
- 两张照片仍可辨认，但整页被重新生成并发生尺寸、排布和视觉细节变化；本次没有证实照片像素不变，不能将成品当作无损修复。
- 输出长边约为原始扫描的 25%，适合屏幕试读，不能当作原扫描清晰度的档案母版。
- 译文嵌在位图里，不能直接搜索、复制或逐句修订；仍应保留可编辑文本层。

结论：单页直译嵌字有可用的试读效果，可作为派生阅读版本；目前不应取代带校对状态的中英对照文本和原图。先保留这一版供比较，不据单页结果批量重绘 272 页。

## Token 用量分析

**本次实际 Token 总量未知，不是 0。** 内置工具仅返回 `image_url` 和保存提示，没有 `usage`、输入图像 token、输出图像 token 或底层模型标识。当前会话的阅读、推理、工具调用和审阅也没有单独用量回执。

提示词为 1497 字符；按英文约 4 字符/token 的粗略经验，约 374 个文本 token，可视为约 300–500 的量级参考。这不是分词器实测，更不是图像请求的总计，且不包含工具可能加入的内部提示。

整页图像编辑的账单至少需区分：文本输入、图像输入、图像输出。使用 Responses API 编排时还应区分外层语言模型用量。页面上的中文字数并不能代表生成图片所耗费的 token，也不能按图片文件字节数换算。

官方文档要求使用响应 `usage` 核算；不同模型、质量和尺寸会改变用量。因此不能把旧模型的 1024×1536 token 表直接套到本次未知模型、1054×1492 输出上。

若后续进行可计量的 API 对照试验，固定模型、输入尺寸、质量和输出尺寸，逐次记录 `input_tokens_details.text_tokens`、`input_tokens_details.image_tokens`、`output_tokens`、`total_tokens`、耗时及重试次数。必须以该接口实际返回的字段为准。单页成本为各类 token 数乘对应单价之和，再加入审阅/重试调用；全书预算宜按正文、图文混排、日文密集页、章扉页分别抽样，而非直接乘这一次用时或字符估算。

本次没有启动外部 API 或第三方图像服务，未产生可核验的 API 账单。

## PDF 提取检查补充

PDF 共 272 页，约 315.5 MiB。元数据为 Canon 与 Adobe Acrobat Paper Capture，结合图像及文字层检查，判断为扫描图加 OCR 文本。

全书已有文字层提取出 417,576 字符；247 页有非空文本，25 页为空。空文字页为 1、2、3、5、6、7、8、14、36、37、58、80、106、156、184、185、214、224、230、231、236、252、253、260、271。其中包括有可见文字的封面、目录及章扉页，不能直接当作空白页跳过。

检查顶层 XObject，272 页各有一张整页 JPEG，宽 4122–4423、高 5826–6101 像素。图书插图和截图通常已合并进整页扫描，并非能逐张直接提取的原始插图。部分样本另有 1×1 inline mask，它们不是有效照片。

已渲染抽查 1、4、5、6、10、30、60、100、140、180、220、260 共 12 页；已提取第 4、60、140、220 页嵌入图像。第 60 页整页 JPEG 清晰，可继续按坐标裁图。

文字主要问题：英文词内多余空格、Undertale 中 l 被误识为 /、阅读顺序混入侧栏、日文被识别为拉丁符号。第 220 页的日文拼写列表在图像中清楚可见，但旧 OCR 已严重失真，需要重新视觉识别与校对。未建立人工逐字真值集，因此不报告全书 OCR 准确率。

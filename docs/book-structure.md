# 页脚、目录与特殊页面

2026-10-23；私人学习项目。

## 固定用语

导航位置只用中文，不附英文或括注。Ruins → 遗迹；Snowdin → 雪镇；Waterfall → 瀑布；Hotland → 热域；The Core → 核心；New Home → 新家；True Lab → 真正的实验室。属于本项目的导航用语约定，不声称是官方译名。Snowdin 在这里指原书该章，不把镇外森林另改成“雪镇森林”。正文讨论名称、双关或拼写时，继续保留需要分析的原语。

## 页脚

只替换原书确实存在的章节／地区标签；不按奇偶规则凭空添加。中文采用思源黑体，字号与原版相近，按原标签右边缘对齐。原页码、颜色与横线保留。页脚作为独立 footer 块，可定位、编辑、保存、载入和导出。模板使用 chapter_id 对应 private/content/book-structure.json；明确的页脚自定义译文优先，避免自动刷新覆盖手动调整。

## 目录

原书目录为第5页，15项。保留原书印刷页码，不按当前导出选页的顺序重新编号。各标题分别为 toc-entry，标题文本、目标页码和 chapter_id 分字段保存；不拿空格或省略号挤出一列页码。数字、原有横线、分栏及章节色标保持原位。目录标题用黑体，不附英文。

viewer 的“目录”按钮回到第5页。选择目录项后可前往已电子化的目标；尚未处理的章节明确提示原书起页。PDF 只在目标页包含于本次导出时生成内部链接，避免悬空跳转；同时生成中文书签。目录项编辑与普通译文使用同一套保存／载入。

## 特殊页面

| 页面类型 | 翻译与排版处理 |
| --- | --- |
| 封面、扉页 | 标题分块翻译；UNDERTALE 标志、作者姓名和原有装饰保留；不伪造中文版出版标志。 |
| 版权、制作名单 | 说明和职责翻译，姓名、机构署名、ISBN、网址、版权符号、许可名称及版本保留。法律声明按原文译出，不改写成私人译本的权利声明。 |
| 阅读指南、对照表 | 表头与说明翻译，字母、读音示例及被比较的语言形式保留；按单元格保存，边框和分隔线不擦除。 |
| 章节跨页图 | 两张原图的比例、裁切与左右页关系保留；只替换原版标题条。没有文字的插图页允许零文本块，不新增标题、页脚或注释。 |
| 致谢页 | 标题、说明和普通句子翻译；人名、网名、机构名与名单顺序保留；原文含玩笑时照原意译，不给每个名字加解释。 |
| 截图、手写字、标志、装饰字 | 当作原始证据保留；原书现有图注译为中文。需要解释时只补必要短释义，不默认生成悬停注释。 |
| 尚不能确认结构的页面 | 保留原图，标为待核；不套普通正文模板、不自动缩字或丢弃内容。 |

每页单独记录 page_role，跨页记录 spread，结构性文本块记录 structure.role。页码依据 printed_page 和 pdf_page，不假设两者在以后添加封面时仍相同。

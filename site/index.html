数据仓库：MrH2T/undertale-localization-zh

令牌只发送给 GitHub API，不存入网址、浏览器存储或代码。关闭或刷新网页后需要重新连接。

第一次使用：如何取得只读令牌
  1. 打开 GitHub 令牌设置，创建 Fine-grained token。
  2. Repository access 选择 Only select repositories，仅勾选 undertale-localization-zh。
  3. Repository permissions → Contents 设置为 Read-only，设置合适的到期时间。
  4. 创建后复制到上方输入框。不要发送到聊天或提交到仓库。
